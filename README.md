## About Project

Sistem infromasi sertifikat menggunkan laravel 8 dengan php 8


### Tutorial

1. clone project ini dengan `git clone `
1. masuk pada folder project jalankan `composer install`
1. masuk ke folder public > jalankan `yarn` (pastikan sudah punya yarn)
1. jalankan `php artisan key:generate`
1. copy `.env.example` menjadi `.env`
1. setting database connection dan mail configuration (pakai mailtrap.io)
1. jalankan `php artisan migrate:refresh --seed` untuk membuat tabel dan data awal
1. jalankan `php artisan serve`
